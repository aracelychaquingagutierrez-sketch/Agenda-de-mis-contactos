# Agenda de Contactos en Python

Este es un programa sencillo en Python que hice para practicar el uso de **colecciones de datos** (en este caso, un diccionario). Sirve para gestionar una agenda de contactos telefónicos desde la consola.

## ¿Qué hace el programa?
- **Guarda contactos:** Permite ingresar un nombre y un número de teléfono.
- **Muestra la lista:** Enseña todos los contactos guardados de forma clara.
- **Busca contactos:** Encuentra el teléfono de una persona buscando por su nombre.
- **Elimina contactos:** Permite borrar a alguien de la agenda si ya no se necesita.

## ¿Cómo probarlo?
1. Descarga el archivo `agenda.py`[cite: 3].
2. Abre la terminal o consola de comandos en la carpeta donde lo guardaste.
3. Ejecuta el archivo con el siguiente comando:
   python agenda.py
